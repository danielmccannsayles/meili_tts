1. Double click launch.command to run!
2. It will open a terminal window; don't be alarmed.
3. The first time running this (or if the folder is moved) will take a minute or two to setup.
4. When the app is ready it will show an icon in the top right menu bar, near date/time, and should open a window on your default browser.
5. Use the icon to quit the app when you're done.
6. Processed files will be saved locally. You can see them in the processed/ folder. Feel free to open this up and copy files out, but try not to change anything as it may break.

Have fun!
